# Instapro

MVP социальной сети для обмена фотографиями

## Первоначальная оценка

20 часов

## Фактически затраченное время

13 часов

## Основной функционал

- **Лента постов** — загрузка и отображение всех постов с сервера
- **Регистрация и вход** — переключение между режимами, валидация полей, загрузка аватара
- **Добавление постов** — загрузка изображения с превью и описанием
- **Удаление постов** — только свои посты, с подтверждением
- **Лайки и дизлайки** — постановка и снятие лайка, счётчик
- **Профиль пользователя** — просмотр постов конкретного пользователя по клику на имя или аватар
- **Выход из аккаунта** — очистка localStorage, возврат к ленте

## Дополнительные улучшения

- **Кнопка «Наверх»** — появляется при прокрутке ленты вниз, плавный скролл к началу
- **Toast-уведомления** — всплывающие сообщения вместо `alert` («Пост удалён», ошибки, подсказки)
- **Скелетоны при загрузке** — пульсирующие плейсхолдеры на месте постов, пока грузятся данные
- **Превью фото перед загрузкой** — миниатюра выбранного изображения до отправки на сервер
- **Форматирование дат** — «только что», «5 минут назад», «3 дня назад» вместо сырой даты
